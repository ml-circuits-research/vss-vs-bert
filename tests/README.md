tests/tiny-bert: a local one-layer BERT configuration and a small WordPiece vocabulary for CPU smoke tests of the scripts without any
download (never a model to report). The fake WikiSQL corpus for the smoke test of models/bert_wikisql.py is generated by the command in
the README (tests/wikisql_fake/, untracked).

Real-data round: `tests/make_fake_real.py` writes tiny FAKE MASSIVE and TOPv2 files (no third-party text; TOPv2 with depths 0-2) into
tests/real_fake/ (untracked); `tests/test_real_data.py` runs the conversion checks on them and, when downloaded, on the real files
(annotation round trips, BIO round trip, gold frames at 1.000, the split files' disjointness).
